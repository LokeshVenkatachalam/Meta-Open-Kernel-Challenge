Kernel notebooks

The useful part is what changed—and what did not work.

Each article ties the retained measurement to its exact source, then separates approach, lessons, failures, and caveats.

Kernel 01

BF16 projections

This workload mixes low-M BF16 GEMMs with a router path whose FP32 weights are represented as BF16 high and low parts. The retained scored source beat SGLang by 1.131876248733277x on the hosted H200 judge.

Measured lesson. Changing router partials from output-major to split-major removed a measured strided-reduction penalty.

Open notebook →

Kernel 02

Attention decode

Attention decode has a small preparation boundary around a much larger paged attention reduction. The retained source beat SGLang by 1.151975903562266x while preserving dense visibility, scaled-cache, and live-slot semantics.

Measured lesson. Removing launch and metadata overhead helped verify and sliding-window shapes, while full B16/B32 attention remained dominated by the FlashAttention-3 main kernel.

Open notebook →

Kernel 03

Routed experts

The routed-expert problem combines top-8 routing over 256 global experts with NVFP4 weights and BF16 activations on an EP8 rank. The retained source beat SGLang by 1.3402887683867017x.

Measured lesson. Routing, alignment, and finalization changes moved the aggregate from a first scored 1.1673x result to 1.3403x.

Open notebook →

Kernel 04

Decoder layer

The whole decoder layer exposes interactions that primitive-only benchmarks miss: attention preparation, paged attention, dense projections, routed experts, and residual normalization share the measured score. The retained source beat SGLang by 1.1855883514963717x.

Measured lesson. Isolated block-size changes raised the measured check from 1.0781x to 1.1343x before boundary fusion added the remaining gain.

Open notebook →

Kernel 05

Prefill layer

The retained prefill kernel is adapted/reused public work from team keell0renz and its vjeux, alygg77, and ZhimaoL lineages. It is not presented as an independently original kernel.

Measured lesson. The public N72 FMHA and LT2 integration raised the campaign from a first scored 1.7859x result to 1.9192x.

How to read the evidence

Checks guide iteration. Scored runs support the published result.

A passing check can be faster than the retained scored run without becoming the leaderboard result. Confidence intervals report measurement uncertainty, not certainty that one implementation dominates every shape or future runtime. Source hashes and paired checks connect the published file to verification.
