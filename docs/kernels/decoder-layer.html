01 · Problem record

What the measured workload asked for.

The whole decoder layer exposes interactions that primitive-only benchmarks miss: attention preparation, paged attention, dense projections, routed experts, and residual normalization share the measured score. The retained source beat SGLang by 1.1855883514963717x.

Its current public position is 1172 of 1299 behind a provisional 2.6144x leader.

02 · Published approach record

What the agentic workflow submitted.

The retained source fuses Q/K normalization, RoPE, FP8 query conversion, and cache stores, then preserves the proven attention implementation.

The expert section uses shape-tuned Marlin blocks, a Triton pre-expert RMS normalization, fused global-to-local expert mapping, and the established post-expert boundary.

Originality caveat: this approach description is not a certification that the implementation was independently authored.

03 · Measured lessons

What changed in the archived measurements.

Isolated block-size changes raised the measured check from 1.0781x to 1.1343x before boundary fusion added the remaining gain.

The exact scored source's paired check was 1.1627x; a later four-warp check reached 1.1644x but did not exceed the retained scored measurement.

Primitive wins required whole-layer validation because attention dominates long full-context shapes while Marlin dominates sliding and verify shapes.

04 · Recorded regressions

Experiments that did not survive measurement.

The first fused candidate failed Triton compilation because a global FP8 constant was not constexpr and therefore has no timing metrics.

Block 8 everywhere, T=256 block 16, and T=32 block 32 each regressed important shapes.

05 · Boundaries

Where this result claim stops.

The last check was accepted before the deadline but finished after close and remained off-board; it is not presented as a scored improvement.

The result is tied to the official H200 shape mix and pinned runtime components, and the rank remains provisional.
