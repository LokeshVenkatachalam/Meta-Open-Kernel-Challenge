01 · Problem record

What the measured workload asked for.

The routed-expert problem combines top-8 routing over 256 global experts with NVFP4 weights and BF16 activations on an EP8 rank. The retained source beat SGLang by 1.3402887683867017x.

It placed 1131 of 1425 in the current provisional snapshot, behind a 2.8438x leader.

02 · Published approach record

What the agentic workflow submitted.

The kernel retains the lossless SGLang Marlin repack and chooses block 8 through 16 tokens, then block 16 for larger batches.

A Triton program maps global expert IDs to the local 0-31 range. A fused finalizer performs per-expert RMS normalization, route weighting, and FP32 accumulation.

Originality caveat: this approach description is not a certification that the implementation was independently authored.

03 · Measured lessons

What changed in the archived measurements.

Routing, alignment, and finalization changes moved the aggregate from a first scored 1.1673x result to 1.3403x.

After those changes, the two Marlin GEMMs still consumed roughly 94-95% of large-shape GPU time.

Every official scored shape in the retained check exceeded the SGLang baseline.

04 · Recorded regressions

Experiments that did not survive measurement.

A persistent Triton SIMT GEMV that decoded canonical NVFP4 directly passed correctness but collapsed to 0.2660x.

Fixed block 32, route materialization, and split W13/W2 block policies regressed part of the shape mix and were rejected.

05 · Boundaries

Where this result claim stops.

Preparation assumes EP8 with local experts 0-31, and the verified timing range ends at 256 routed tokens.

H200 does not provide Blackwell native NVFP4 tensor-core MMA; the implementation dequantizes for supported Hopper compute.
